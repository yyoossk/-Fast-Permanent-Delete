# 高速完全削除 / Fast Permanent Delete

Windows用のシンプルな完全削除ツールです。
ファイルやフォルダを**ゴミ箱へ移動せず直接削除**できます。

A simple permanent deletion tool for Windows.
It deletes files and folders **directly without moving them to the Recycle Bin**.

## 主な機能 / Features

* ファイル・フォルダの完全削除 / Permanently delete files and folders
* 複数ファイル・フォルダに対応 / Supports multiple files and folders
* ドラッグ＆ドロップ対応 / Drag & drop support
* 削除前の確認 ON / OFF / Confirmation before deletion can be enabled or disabled
* 確認ON時は「はい / キャンセル」 / Yes / Cancel when confirmation is enabled
* 確認OFF時はGUIを表示せず即時削除 / Silent deletion when confirmation is disabled
* GUI起動中は続けてファイルを追加可能 / Add and delete more files while the GUI remains open
* 多言語対応 / Multi-language support
* 国旗付き言語選択 / Language selection with flags
* 32bit通常版 / 64bit版 / 32-bit and 64-bit versions

## 使い方 / Usage

### ファイルを削除 / Delete files

削除したいファイルやフォルダを `高速完全削除.exe` にドラッグ＆ドロップします。

Drag and drop the files or folders you want to delete onto `高速完全削除.exe`.

### 設定変更 / Settings

`高速完全削除.exe` を普通にダブルクリックして起動します。

Double-click `高速完全削除.exe` normally to open the settings window.

設定できる項目：

* 削除前に確認する / しない
* 表示言語

Available settings:

* Enable / disable deletion confirmation
* Display language

## 対応環境 / Supported Systems

* Windows
* 通常版：32bit / Standard version: 32-bit
* 64bit版：64bit Windows向け / 64-bit version: for 64-bit Windows

## ⚠ 注意 / Warning

このアプリで削除したファイルやフォルダは**ゴミ箱には入りません**。
削除後の復元が困難になるため、重要なファイルを削除しないよう注意してください。

Files and folders deleted with this application **will not be moved to the Recycle Bin**.
Recovery may be difficult or impossible, so please use this tool carefully.
